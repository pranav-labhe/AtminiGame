# Atmini Game — tiny Android prototype

This is a deliberately small proof-of-concept game using the exact Atmini artwork supplied in the project.

## What is included

- `app/src/main/res/drawable-nodpi/atmini.png` — 768px transparent render of the supplied artwork, used by the prototype.
- `source-art/atmini_original.svg` — original 2048×2048 SVG source (kept outside the APK resources).
- Kotlin `GameView` with movement, jump, collectibles, camera scrolling, score and restart.

## Controls

- ◀ / ▶ — move Atmini
- JUMP — jump
- Collect the glowing orbs.
- After the run ends, tap to restart.

## Important artwork note

The supplied artwork is an SVG containing about 11,937 paths generated by VTracer. It is not currently a semantic Android VectorDrawable with named groups. Therefore this prototype rasterizes the exact artwork to a PNG for reliable Android rendering.

The next step, if desired, is to turn the artwork into a real game character rig: separate body/hair/cloak/arms/face layers and animate those independently. That is a different conversion from simply using the existing SVG as a sprite.

## Open in Android Studio

Open the `atmini_game` folder as an Android Studio project. No external libraries are required by the app module.
